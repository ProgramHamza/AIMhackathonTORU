Reading the chart

  • The offline lane fills the fact store. The online lane reads it and only calls a model for unstored questions and for the summary.
  • Hackathon: model calls go to cloud APIs behind a swappable interface. Hospital: the same pipeline on local servers.
  • Not built: FHIR/HL7 integration. Documents are loaded from files.
