Prompt analysis: which setup works best

How well each setup turns a clinician's request into the checklist of facts to look for. Generated 30 Oct 2026 02:24. Labels were written by the team, not by clinicians.

The setups compared

  • Old tree: First version: fixed rule tree with keyword matching, no LLM.
  • Graph: Weighted graph (roles, tasks, situations, drugs, procedures) with keyword matching, no LLM.
  • Graph + Gemini: Graph, and Gemini is asked online whenever the prompt has words the graph does not know.
  • Graph + generated vocabulary (default): Graph plus 750 synonyms and 195 clinical concepts that Gemini generated once, offline. No model call at query time. This is the default.
  • Generated + Jina embeddings: Generated graph, plus Jina embeddings to link words the graph still does not know (one API call, about 2.6 s).
  • Generated + Gemini: Generated graph, plus Gemini online for words still unknown.
